MySQL and MariaDB state adapter for [Queuert](https://github.com/kvet/queuert) — a job-chain library: durable, typed background work in your database.

## Installation

```bash
npm install @queuert/mysql
# or
pnpm add @queuert/mysql
# or
yarn add @queuert/mysql
```

**Peer dependencies:** `queuert`
