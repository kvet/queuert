# Queries Showcase

Read-only query methods for inspecting chains, jobs and workers.

Scenarios: single lookups with type narrowing, batch lookups, type discovery, per-status type counts, paginated lists, jobs within a chain ordered by chain index, blocker queries from both directions, worker lookups, counts and lists.

## Running

```bash
pnpm install
pnpm --filter example-showcase-queries start
```
