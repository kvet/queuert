The lessons ran on PostgreSQL in PGlite or SQLite in sql.js, inside your browser. In your app the same Queuert code runs against your own database server; the state provider that wraps your client and the transaction you pass in change.

## Requirements

- Node.js 24 or later
- TypeScript 5.2+ (the examples use `await using`)

## Install

Pick one state adapter, optionally a notify adapter and any extras; the command below installs the core `queuert` package together with them, and the code on this page follows your picks. Your picks are saved in this browser.

<InstallPicker />

The command covers Queuert and its adapters, not your database client. Install the driver the code below uses the same way, or pick another one on the adapter's page.

## Process

Declare job types with `defineJobTypes` and write processors as in the lessons. Each handler commits its outcome through `applyJobOutcome` inside a transaction.

## Notify workers

Without a notify adapter, the client wakes its own worker runners in memory and workers in other processes poll the database. A notify adapter wakes them as soon as a chain is created; pass it to `createClient` as `notifyAdapter`.
