`awaitChain` waits for a chain to complete by combining polling with notify adapter events. Between polls, it listens for completion notifications to react immediately.

```ts
const completedChain = await client.awaitChain(
  { id: chainId },
  { timeoutMs: 30_000, pollIntervalMs: 5_000 },
);

console.log(completedChain.output); // Typed output from the final job
```

`awaitChain` takes the chain (or any `{ id }`) and options: `timeoutMs` is required, `pollIntervalMs` sets how often the database is polled between notifications (default 15 seconds), and `signal` accepts an `AbortSignal`. It runs outside any transaction, so several chains can be awaited concurrently:

```ts
const completedChains = await Promise.all(
  chains.map(async (chain) => client.awaitChain(chain, { timeoutMs: 30_000 })),
);
```

Both a timeout and an abort throw `WaitChainTimeoutError`:

```ts
try {
  await client.awaitChain({ id: chainId }, { timeoutMs: 30_000, signal: request.signal });
} catch (error) {
  if (error instanceof WaitChainTimeoutError) {
    /* timed out or aborted */
  }
}
```
