The worker's lease is not a runtime limit: it bounds how long a crashed worker's jobs wait before another worker picks them up, and a handler may run far longer than its `durationMs` because the heartbeat keeps renewing it. Use the cooperative `job.signal` pattern above for real runtime limits. The [Worker runner](/queuert/how-it-works/worker-runner/#worker-lease) owns the lease, its heartbeat and reclaim.

The worker runner below holds a lease of 1000 ms, renewed every 300 ms, and `rebuild-search-index` waits for its `job.input.durationMs`, which the example sets to 3000 ms: it completes on its first attempt because the heartbeat keeps renewing the lease.
