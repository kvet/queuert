## Requirements

- Node.js 24 or later
- TypeScript 5.0+ (recommended)

## Installation

Pick one state adapter, optionally a notify adapter and any extras; the command below installs the core `queuert` package together with them. Your picks are saved in this browser.

<InstallPicker />

For detailed adapter configuration (ORM setup, driver options, provider interfaces), see the [Integrations](/queuert/integrations/) section.
