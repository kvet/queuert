## Requirements

- Node.js 24 or later
- TypeScript 5.0+ (recommended)

## Installation

<Steps>

1. Install the core package:

   <Tabs syncKey="pkg">
     <TabItem label="npm">
       ```bash
       npm install queuert
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```bash
       pnpm add queuert
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add queuert
       ```
     </TabItem>
   </Tabs>

2. Install a state adapter (pick one):

   <Tabs>
     <TabItem label="PostgreSQL">
       Supports horizontal scaling and all Queuert features.
       Requires PostgreSQL 14+. See [PostgreSQL State Adapter](/queuert/integrations/state-adapters/postgres/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/postgres
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/postgres
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/postgres
           ```
         </TabItem>
       </Tabs>
     </TabItem>
     <TabItem label="SQLite">
       Suitable for local development, CLI tools, and embedded applications. Requires SQLite 3.42+.
       See [SQLite State Adapter](/queuert/integrations/state-adapters/sqlite/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/sqlite
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/sqlite
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/sqlite
           ```
         </TabItem>
       </Tabs>
     </TabItem>
     <TabItem label="MySQL / MariaDB">
       <Aside type="caution" title="Experimental">
         `@queuert/mysql` is experimental: its API may change in a minor release.
       </Aside>

       For applications whose data lives in MySQL or MariaDB. Requires MySQL 8.4+ or MariaDB 11.4+ (InnoDB).
       See [MySQL / MariaDB State Adapter](/queuert/integrations/state-adapters/mysql/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/mysql
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/mysql
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/mysql
           ```
         </TabItem>
       </Tabs>
     </TabItem>
     <TabItem label="Redis">
       <Aside type="caution" title="Experimental">
         The Redis state adapter in `@queuert/redis` is experimental: its API may change in a minor release.
       </Aside>

       Queuert's state on Redis or Redis Cluster, kept apart from your application database. Requires Redis 6+.
       See [Redis State Adapter](/queuert/integrations/state-adapters/redis/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/redis
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/redis
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/redis
           ```
         </TabItem>
       </Tabs>
     </TabItem>
   </Tabs>

3. (Optional) Install a notify adapter for reduced latency:

   <Tabs>
     <TabItem label="PostgreSQL LISTEN/NOTIFY">
       Uses PostgreSQL's built-in `LISTEN`/`NOTIFY`. No additional infrastructure beyond your
       existing PostgreSQL database — already included in `@queuert/postgres`. See
       [PostgreSQL Notify Adapter](/queuert/integrations/notify-adapters/postgres/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/postgres
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/postgres
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/postgres
           ```
         </TabItem>
       </Tabs>
     </TabItem>
     <TabItem label="Redis">
       Uses Redis pub/sub. Requires Redis 6+. See
       [Redis Notify Adapter](/queuert/integrations/notify-adapters/redis/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/redis
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/redis
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/redis
           ```
         </TabItem>
       </Tabs>
     </TabItem>
     <TabItem label="NATS">
       <Aside type="caution" title="Experimental">
         `@queuert/nats` is experimental: its API may change in a minor release.
       </Aside>

       Uses NATS pub/sub. Requires NATS 2.2+. See
       [NATS Notify Adapter](/queuert/integrations/notify-adapters/nats/).

       <Tabs syncKey="pkg">
         <TabItem label="npm">
           ```bash
           npm install @queuert/nats @nats-io/nats-core @nats-io/transport-node
           ```
         </TabItem>
         <TabItem label="pnpm">
           ```bash
           pnpm add @queuert/nats @nats-io/nats-core @nats-io/transport-node
           ```
         </TabItem>
         <TabItem label="yarn">
           ```bash
           yarn add @queuert/nats @nats-io/nats-core @nats-io/transport-node
           ```
         </TabItem>
       </Tabs>
     </TabItem>
     <TabItem label="None">
       No extra packages or infrastructure required. The client wakes its own worker runners in
       memory, and workers in other processes poll the database on a configurable interval. See
       [Without a notify adapter](/queuert/integrations/notify-adapters/#default).
     </TabItem>
   </Tabs>

4. (Optional) Install additional packages, covered in [Observability](/queuert/integrations/observability/):

   <Tabs syncKey="pkg">
     <TabItem label="npm">
       ```bash
       npm install @queuert/dashboard  # Embeddable web UI for job observation
       npm install @queuert/otel       # OpenTelemetry metrics and tracing
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```bash
       pnpm add @queuert/dashboard  # Embeddable web UI for job observation
       pnpm add @queuert/otel       # OpenTelemetry metrics and tracing
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add @queuert/dashboard  # Embeddable web UI for job observation
       yarn add @queuert/otel       # OpenTelemetry metrics and tracing
       ```
     </TabItem>
   </Tabs>

</Steps>

For detailed adapter configuration (ORM setup, driver options, provider interfaces), see the [Integrations](/queuert/integrations/) section.
